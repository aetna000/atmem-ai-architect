# AWS document-task contract — offline evidence

Eight checks validate the emitted EC2/ECS request against the pinned official botocore1.43.123 ECS model. SDK parameter validation alone omits enum enforcement, so the independent verifier recursively enforces the native enum sets. The initial Docker none log-driver request was caught and retained.

The module preserves source bytes outside task metadata, uses separate input/output task-scoped local volumes, orders successful download/parser/upload, keeps the first two containers nonessential so early completion does not stop the upload, disables parser networking and restricts placement to a reviewed dedicated-host policy fingerprint.

This is an unfinished implementation block. The referenced transfer CLI, native launcher, recovery, dedicated-host attestation, Terraform and whole-package integration still need implementation. No default worker/capability is enabled. A scheduler attribute is a selection constraint, not proof of host policy. Omitted per-container logging requires verified Docker daemon default none. ECS EC2 containers share a kernel; this is not a VM or hostile-kernel escape boundary. No cloud operation was performed.
