# Public FAQ composition and qualification checkpoint

This increment implements a shared public-only retrieval/catalog/editor/HTTP core,
four native hosting/storage/identity/model compositions and concrete export/Spec Kit
interfaces. It is not the completed 28-project programme or a deployment claim.

Fresh full-business-brief conversations on AWS, Azure, Google and IBM each converged
in three exchanges, one country question and zero technical questions. Their exact
original packages pass independent static assessment, dependency metadata closure,
emitted Python checks and native Terraform schemas/mock plans. AWS is v22; the other
three are v19. Subsequent v24 compiler-only exports preserve their projects and
requirements while correcting setup instructions and recording current cost drivers.
All four current exports also pass source/provider and exact Linux artifact checks.
See qualification-summary.json for original/current paths, hashes and receipts.

The public browser/API admits anonymous visitors but can read only its dedicated
private catalog. A separate existing company editor role/group receives scoped
conditional write authority. The operator CLI supports public UTF-8 file ingestion,
updates and deletions with native ETag/generation preconditions. Runtime retrieval
uses complete articles, verifies citation IDs/quotes and rechecks source freshness
before returning. Unknown, unavailable or changed evidence fails closed. There is
no private document connector, arbitrary URL fetch or application editing endpoint.
An explicit typed operator interface connects the editor actor to its actual CLI.

The first v18 exports retained an untyped editor connection and correctly failed.
v19 fixed that contract. Its AWS App Runner design then exposed a lifecycle defect:
App Runner is closed to new customers, despite valid provider schemas/mock plans.
That earlier static candidate is NOT accepted. The current independent assessor
rejects it; the posthoc assessment and old source/conversation remain preserved.
The default AWS composition now uses Lambda/HTTP API v2, the reviewed hash-pinned
Mangum adapter, a deterministic Linux x86_64 ZIP and five reserved executions. It
needs no App Runner eligibility question, ECR repository or always-on container.

The exact AWS ZIP runs in a pinned official AWS Python 3.13 Linux image, nonroot,
read-only and network-disabled. Native wheel versions/origins, the actual entrypoint,
HTTP API events and 39 emitted acceptance checks pass. Original and current ZIPs
have the same SHA256, demonstrating reproducibility across unchanged source. Azure,
Google and IBM images pass startup/public assets/origin denial/source-outage checks
and their emitted catalog/HTTP/transport suites. These use scripted model/storage
transports, not live cloud identities or model APIs.

The local signed-in model probe passes nine synthetic fact/source tests: known
answers, related-topic abstention, no-source abstention, question/article injection,
a fact at the end of a long article, update and deletion. This is one local-model
sample per case, NOT four cloud-model semantic evaluations or universal entailment
proof. Eight browser checks pass; desktop/mobile screenshots were inspected.
Regression checkpoint: 293 JavaScript tests, 205 server tests and build pass.

Stricter Azure plan-time mocks found a real prior template omission: a configured
health-check path requires health_check_eviction_time_in_min. Both private and public
templates now supply it. Native fault challenges remove only that field in isolated
copies and confirm the provider rejects the result. Exact regenerated private Azure,
Google and IBM ticket-triage source/Linux regressions also pass. Original artifacts
and their earlier weaker evidence are preserved; a mock pass was not retroactively
treated as proof of a correct old template.

Security evidence remains scoped and open. The exact Lambda ZIP rootfs scan detects
all 29 packaged distributions and reports no vulnerabilities. A filesystem scan
initially detected zero packages and was discarded as insufficient evidence; its
report/log is retained. The official AWS qualification image separately reports six
fixable high findings in bundled tooling/dependencies and the local runtime emulator;
those components are absent from the exported ZIP. This is not proof of the managed
Lambda runtime's patch level. Original Azure/Google/IBM image scans each report zero
critical, 47 high without reported fixes and zero fixable high findings; those high
findings remain open. Full reports are retained, not filtered into a clean claim.

Archives include failed and successful source/receipts, original handoffs, current
generator checkpoint, scoped primary documentation snapshots, browser and model
probe evidence. Reproducible build wheels/ZIPs, installer caches, provider binaries,
node_modules and private/ephemeral memory stores are excluded; their locks, source
hashes, build hashes and logs are retained. No exported client bundle was hand-patched.

Remaining work includes the medium/hard native connectors, durable approved workflows,
tenant memory/credit controls, complete strengthened 28-case rerun and broader held-out
acceptance. Real destination IAM, model availability/policy/quality/latency, quotas,
prices, account plans, production state/operations and deployments remain unverified.
No image publication, cloud account operation, repository push or deployment occurred.
