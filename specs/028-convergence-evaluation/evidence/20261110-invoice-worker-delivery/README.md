# Invoice worker, delivery and operations qualification

This is a component/composition checkpoint, not a completed benchmark project.
See summary.json for observed counts and explicit remaining work. CV-005 remains
in progress; no medium case, cloud plan, deployment or production acceptance is claimed.

The native AWS adapter emits private application/parser/database/network boundaries,
invited staff identity, immutable repositories, versioned objects, scoped identities,
native secret references, operator outputs and operating instructions. Six native
Terraform mock runs pass. The actual delivery image starts with the native mock-plan
API environment and creates the bounded worker from the emitted worker environment.

The four provider images have separate pinned SDK dependency sets and pass actual
startup and five restricted local queue cases each. IBM dateutil 3.0 is intentionally
resolved against its native SDK; it is not borrowed from the other clouds' fixtures.
The parser runs separately over private TLS RPC; only the local qualification fixture
owns Docker access. Production worker images do not receive a Docker socket.

Retention denies expired payload access before reads/model/actions and supplies an
operator-only bounded SQL purge. Real local pg_dump/pg_restore verifies restore
quarantine, expiry cleanup and explicit independently supplied receipt reconciliation.
The operator maintenance window still needs native scheduling/bootstrap delivery;
these local checks do not prove managed PITR, physical deletion deadlines or RPO/RTO.

Retained failures include missing emitted modules, concurrent cold SDK client
creation, provider JSON route syntax, nullable data defaults, unknown certificate
iteration keys, test syntax/output-buffer faults, fixture namespace mismatch and
restore search-path setup. Compiler/runtime repairs preserve scope and tests.

source-snapshot retains exact repository bytes covered by source receipts. Native
provider schemas are pinned separately; verbose mock logs preserve full native plans
while replacing repeated whole-provider schema catalogues with their hashes. Raw
native-output hashes remain in the qualification receipt. No secret or SQL dump is
published here. Historical failed artifacts/receipts remain failures.

Application images have 47 open unfixed high vulnerability findings each; parser
has 65. Neither is a clean scan or an accepted production security posture.
