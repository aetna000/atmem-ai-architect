# Private Google document substrate

Generated from the owned design; this is one unfinished composition block, not a complete project. Use the same selected region, owned destination and existing question-worker identity. Terraform manages only the declared bucket, parser VM identity, custom roles, private registry/network/DNS and API prerequisites. It does not create a user website, company identity provider or document sources.

The controller gets four project-scoped Batch permissions and actAs only on the transfer VM identity. Object permissions are separate custom roles bound solely to the ephemeral bucket; the transfer VM cannot delete objects or access source/model/SQL credentials through these grants. Existing inherited permissions still require account inspection.

Build/review immutable artifacts after the foundation and set images_ready only with real build receipts. Foundation output is null; image inputs contain no synthetic published digest. Generated runtime configuration matches enterprise_google_jobs.py. Application hosting, provider/artifact binding, durable orphan recovery, key/audit operations and complete Spec Kit/export integration remain unfinished. No private capability or whole-case acceptance is implied.

Ordinary completion deletes temporary input/results. Bucket versioning and soft deletion are disabled to avoid hidden retained copies. No retention lock or replication is requested. Age-one-day lifecycle is an asynchronous last-resort cleanup request; it does not provide a strict upper retention bound or replace the required reconciler. Observe organization policies and deletion propagation in the destination before release.

VMs have no external IP in the emitted runtime request. Private Google Access, private googleapis.com/pkg.dev DNS, explicit private API routes, TCP443 allow rules and deny-all egress/ingress supply the substrate. Batch-container network isolation and actual VM/agent/IAM/DNS behavior require destination testing; mock plans do not prove those behaviors. No cloud apply or deployment was performed.
