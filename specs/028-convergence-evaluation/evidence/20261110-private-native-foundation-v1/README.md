# Private native-source foundation

The original private-knowledge scenario remains unchanged. Native REST adapters
and the per-request authorization/retrieval coordinator are implemented but not
wired into public generator capabilities. See the archived architecture decision
and explicit remaining dependencies. 23 scripted contract/policy tests pass.
The initial syntax failure and corrected initial adapter run are preserved alongside
the final 23-test command. This is not a vendor-account, OAuth, deployed integration,
10,000-document benchmark or whole medium-case acceptance claim.

Primary documentation URLs, API versions, retrieval times and content hashes are
preserved. Raw public documentation snapshots remain in local review storage;
none is treated as instructions, executable input or client project material.
