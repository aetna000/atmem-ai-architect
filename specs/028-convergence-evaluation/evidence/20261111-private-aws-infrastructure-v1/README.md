provider-mock plans. Independent consumers inspect actual positive output, 45
resources and43 IAM action occurrences against pinned official authorization
metadata, runtime shape/native ECS schema and exact host command/bootstrap bytes.

without network access. Native systemd-analyze accepts the emitted guard/drop-in

expectation issues, double-escaped cloud-init header, trust-template expression
