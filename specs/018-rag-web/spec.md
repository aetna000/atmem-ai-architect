# Authenticated browser application

Generate private S3/CloudFront hosting, Cognito administrator-created users with software-token MFA, authorization-code/PKCE sign-in and a scoped JWT API route. Keep end-user tokens in memory, reject incorrect OAuth state and render answers/citations as plain text. Preserve the IAM qualification route independently. The runtime reads authoritative identity/employee-region mappings and rechecks authorization before model access and delivery.

No passwords belong in Terraform or source control. Onboarding and disabling users are explicit operator actions with receipts. Live Cognito/MFA, authorization, recovery and browser acceptance remain separate from local transport fixtures.
