# AtMem infrastructure and cost review gate

Owner-directed implementation of `atmem-review-hook/PLAN.md`, on a new branch from main. The supplied scaffold is design evidence; its claimed prior validations are not current execution evidence.

The product reviews supplied plan text and optional Terraform show JSON against a separate architecture policy. It returns pass/warn/fail, exact evidence, suggested fixes and explicit unknowns. It never generates/runs Terraform, reads arbitrary client paths, edits customer files or calls cloud-provider APIs. Caller artifact paths are citation labels only.

1. Deterministic checks cover structured attribute predicates, provider regions, service restrictions and public ingress. Unknown/computed/deferred values, missing scope or unsupported rules cannot earn a pass.
2. Budget checks require a real attributable cost-engine result in the matching currency and environment. Missing/partial pricing is unverified; illustrative sample costs are never measured evidence.
3. Prose/ADR interpretation is a separately enabled model adapter. No source leaves the reviewer by default. Model findings require exact validated citations; source text cannot grant permissions or override policy.
4. Expiring exceptions retain the original violation and accepted exception identity. No silent suppression.
5. MCP stdio exposes only review_plan with input/output validation and bounded payloads. A local CLI provides machine JSON and CI exit codes; no private artifact persistence by the reviewer.
6. Spec Kit/OpenSpec integrations consume actual review output and document prompt/file-existence enforcement limits. A CI command must reject failed, stale or missing review evidence.
7. Deliver a runnable local package, before/after demo generated by the actual engine, tested installation instructions and exact coverage limits. Publishing, catalog submissions, hosted execution, paid model calls and a live pricing credential run remain separately authorized or access-dependent.

No revenue or adoption is established by this implementation. The commercial entry point is infra/cost-policy enforcement inside existing agent workflows; hosted team policies, usage/billing and commercial rollout follow demonstrated local behavior.
