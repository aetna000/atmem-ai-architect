Build a small offline classroom climate-file viewer. A teacher chooses a local UTF-8 JSON file and sees its room name, sample count, minimum, maximum and mean temperature in degrees C. Display temperatures to one decimal place. This is a static browser tool: no account, backend, cloud, AI, CDN, package download or network submission. File contents and derived values must stay in the current page only; do not persist them in browser storage.

The file is at most 64 KiB and has exactly two fields: room (a nonblank string of at most 80 characters) and samples (an array of 1–1000 finite JSON numbers, each between -50 and 70 inclusive; booleans/strings are invalid). Show useful safe validation errors for malformed JSON, wrong fields/types and out-of-range/oversized files. Render room names as plain text. A clear control must remove file/room/results/errors. Choosing another file must replace the previous results, and clearing or choosing another file while it is being read must prevent an old result from reappearing.

Supply the actual portable static HTML/JavaScript files, meaningful automated tests, and concise local preview/test instructions and limitations. Preserve backend-supplied inputs. No existing systems are to be changed.
