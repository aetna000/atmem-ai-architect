# Supplied-image identity, network and lifecycle safeguards

GE-005 checkpoint, not alpha.4 or a complete-project qualification. Three runnable
increments and one of28 original full local qualifications remain the current
counts; owner acceptance is zero and measured quality is unknown.

The reusable contract applies to any explicitly selected supplied-image container
unit, standalone or composed, without project-name/domain dispatch. It retains
configured providers, region and ownership. It does not implement the supplied
application or imply its connection/runtime behavior has passed.

`before.json` records the db1abd9 counterexample: replacing an owned execution
policy with all actions/all resources produced no fatal finding and still claimed
infrastructure complete. The address footprint alone did not protect IAM semantics.
`after.json` records rejection of the equivalent current-output mutation.

Implemented:

- AWS reads exactly the supplied existing subnet/security-group IDs through the
  unit provider, and native service preconditions require a shared explicit VPC.
  IDs are distinct, nonempty and syntactically checked. Networks are not created,
  modified or imported. Shared-VPC ownership is not silently rewritten.
- AWS task and execution role trust retains ECS service principal, source account
  and regional source ARN. The execution role permits only ECR token/retrieval and
  the owned log streams; repository input excludes wildcards. The runtime task
  role has no application grants. An independent semantic JSON check rejects
  policy/trust/role/task mutations and tolerates JSON ordering changes.
- Every managed supplied-image resource retains prevent_destroy, a review-gate
  dependency and its reviewed instance identity. Cloud Run retains native deletion
  protection. Independent inspection rejects hidden changes, unreviewed provider
  options, altered immutable-image guards and destination overrides.
- Generated instructions describe these boundaries and replacement review. AWS
  instructions appear only on AWS units; other provider instructions remain local
  to their own contracts.

VPC membership and no public task IP do not prove private routing, firewall/egress,
reachability or end-to-end security. IAM mocks are not AWS IAM simulation or account
authorization. Lifecycle protection can be removed by configuration edits or by
removing resource configuration; it is not state locking or a backup. Replacement
image revisions may require a separately reviewed lifecycle change and plan.
Parent composition gates may defer data reads; resolved unit plans exercise the
preconditions separately. No cloud reads/plans/apply, image execution, deployment,
owner acceptance or new full-system qualification occurred.
