# Native reviewed-evidence and registered-check bridge

Source checkpoint qualification: 336 server tests, no skips. This is not yet a real
native tool invocation qualification, software release or accepted project.

Reusable capability: portable project/workspace/turn/call-bound tools expose pinned
reviewed engineering knowledge and immutable settled-artifact checks to the native
harness. The Codex adapter supplies thread identity and registers the function tools;
core dispatch never receives a native handle. Unknown RPC requests and approvals
remain denied. Async tool handlers do not block protocol responses/progress; payload,
response, task and per-turn call bounds apply. No model/browser command, image, host
path, daemon or tenant selector is enabled.

The backend-owned knowledge snapshot is separate from project memory. Search returns
explicit corpus scope/provenance and complete record reads retain all reviewed fields.
Current eligibility, exact pinned record equality and source validation exclude stale,
revoked/changed guidance rather than replacing it silently. This small local curated
corpus is not live vendor research, exhaustive knowledge or an AtMem retrieval service.

Calls are durably reserved before effects. Matching completed calls reuse their saved
reply; changed arguments for the same identity are rejected; reserved/lost replies
remain uncertain and do not replay work. Registered validation retains its independent
immutable-artifact/contract deduplication and recovery behavior. Evidence outputs have
explicit character pages, total length/digest and nextOffset; complete reads are not
silently truncated. Prior package receipts do not validate later working edits.

Transfer/counterexamples: full reviewed evidence across AWS/Azure/GCP/IBM, a >3000
character record, module artifact checks and multipart Unicode output; foreign scope,
workspace, turn, artifact/check IDs; raw execution arguments; changed/revoked records;
reused call identities and reserved-call restart; malformed/oversize tool replies and
approval denial. Real harness/worker execution and server-restart transfer pending.

Active working checkpoint capture/browser validators are intentionally not claimed.
Delivery capture still requires a settled run. The isolated Chromium prototype remains
operator-only. Next qualify actual native callbacks with a distance-module requirement
change and restart, then add controlled in-progress checkpoints/isolated browser checks
and generic validation/repair ownership without weakening settled delivery gates.
