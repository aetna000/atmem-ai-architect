## Reusable implementation and safeguards

Independent admission derives allowed delivery units and canonical local paths from
the project and reviewed capability catalogue, not emitted metadata. It inspects
actual root/child configurations, resources and provider arrays. Provider/input/
output bindings, sensitivity/type/default/validation contracts, approval/unfinished
scope, source ownership and required native-test files remain checked. It rejects
foreign or nested modules, extra Terraform, execution hooks, external state readers,
embedded credentials, missing resources, borrowed aliases, instance expansion and
forged metadata. A provider present in one unit cannot justify another unit's
wrong-cloud resources. Unsupported requirements/interfaces stay visible/blocking.

Implementation maps list actual module resource addresses, files, root input names
and root/unit-local commands. Invoice tasks/documents now iterate every unit with
distinct existing task IDs, scoped source paths/inputs and separate phased DAGs;
supplied-container tasks explicitly require the owner-supplied image/runtime tests.
Every generated task file reference is checked against actual emitted files. Root
state remains composition-owned and production stays blocked pending its required
implementation/acceptance. Existing systems/source, requirements and exact model/
effort are preserved. No evaluation IDs or private domain templates dispatch code.

The trusted server generator reports independently inspected modules. The Terraform
validation service runs each module's provider initialization, schema and native
mock tests; empty, skipped or failed module tests cannot be a pass. API callers
cannot submit executable Terraform. UI/download receipts downgrade older root-only
service responses to incomplete until all current unit identities, schema stages
and nonempty mock-test results are present. Existing services remain running. All subprocesses retain credential-free
environments and backend-disabled initialization. Configured provider caches use
an explicit filesystem mirror; no arbitrary module source is admitted.
