# AtMem AI Architect 0.2.4

Terraform apply emulation runs the real Terraform CLI and AWS provider against a local AWS API, then checks SDK read-back, zero-change convergence, destruction and configured leak inventories. The Board shows actual resource lifecycle events and exports the report.

Moto 5.2.5 supplies the base API. AtMem engines add CloudFront, Step Functions validation, Cognito resource-server deletion, image-based App Runner services, OpenSearch Serverless lifecycle repairs, Bedrock content-policy guardrails and vector knowledge-base registration. RDS, S3, SQS, Lambda and CloudWatch compatibility repairs remain explicit in reports.

Measured local receipts: 22/22 fixtures, 89 resource types and 7/7 archived AWS projects pass. This measures those configurations; other AWS services and configurations remain unmeasured. IAM enforcement, encryption, actual compute execution, model inference, vector indexing, ingestion, retrieval and real AWS account acceptance are outside this evidence.

The npm launcher prepares a separate hash-locked emulator Python environment. Terraform 1.7+ must be installed separately. Hosted execution uses a registered immutable image, tenant/project ownership checks and a nonroot container with no external networking, credentials, host mounts or Docker socket. Hosted publication and host canary evidence are tracked separately in Spec Kit 032.

Run `npx @atmem/architect@0.2.4`. On Board, choose **Emulate apply**, then run and download the result. No cloud resources are deployed by this operation.
