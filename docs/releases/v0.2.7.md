## Verification and limits

The local candidate passed 782 JavaScript tests, clean-installed browser checks for waiting feedback and layout recovery, and responsive workspace checks at 1440, 900 and 390 pixels in light and dark themes. The deliberately colliding synthetic page improved from 15 conflicts to zero; remaining conflicts on other diagrams remain visible.

Routing measurement improved from 9094 ms to 601 ms on the same locally retained diagram with identical routes. This measures local UI work; provider inference and network latency still vary. No C++ or WebAssembly runtime is required.

Release CI separately qualifies the exact package on macOS, Linux and Windows before trusted npm publication. Full native Windows generation/export and Windows/Linux Orca desktop execution remain unqualified. Source and package privacy checks inspect nested archives using the private release policy; client evidence stays local.
