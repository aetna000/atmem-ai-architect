# AtMem AI Architect 0.2.1

Stable maintenance release.

```sh
npx @atmem/architect@latest
```

## Changes

- AtMem runtime upgraded to2.3.14, with locked dependencies and verified preservation of2.3.10 data.
- Available cost estimates use a normal Estimated state with clear exclusions. Regional pricing and placement actions are improved.
- Delivery opens promptly; PDF/diagram generation waits for explicit preview or export. Complete exports retain their documents.
- Generation shows a live activity bar and animated event counter. Previous files are clearly distinguished from active generation.
- Terraform validation and application tests have separate Run actions, disabled during generation with prerequisite explanations.
- Large validation requests use checksummed, ordered128 KiB chunks instead of failing at the small-request API boundary.
- A dismissible GitHub-star invitation appears after successful export.
- [AtMem AI Architect for Orca](https://orca.dev/plugins/aetna000/atmem-ai-architect-orca) adds branded local startup and handoff inspection.

## Validation and scope

587 JavaScript tests, focused real-browser checks and523 server tests (12 documented skips) passed locally. Packaged UI and real AtMem startup passed in CI on Windows, macOS and Linux before publication.

The current saved-design Terraform draft passed local generation consistency, provider initialization and schema validation. An explicitly registered isolated Python/PostgreSQL runner passed22 tests on the current captured application package. Those are local observations; the runner is not installed/configured by npm. [Configuration guide](../architecture/configuring-application-tests.md).

Chunk transport admits requests up to64 MiB while preserving existing project-document/context admission limits. Terraform validates the saved-design draft, not arbitrary model-generated files. Missing checks, browser-runtime qualification and account/cloud acceptance remain explicit. No cloud deployment occurs automatically.
