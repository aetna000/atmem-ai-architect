# AtMem AI Architect 0.2.5

- Edit Requirements directly in one document. Use the formatting toolbar, insert pages, tables and images, and comment on selected text. Review tracked edits page by page. Accepted edits to linked requirement text update the architecture model.
- Navigate nested blocks and edit architecture diagrams, interfaces and verification cases.
- Start the local server with `atmemai`. Use `atmemai status` to see versions and storage paths. Restart and stop ask for confirmation. Connect a model with `atmemai login NAME`.
- Local installations bundle the setup for Terraform apply emulation and report the exact implementation gaps when an emulation is blocked.
- AtMem memory uses the pinned 2.3.15 runtime.

```sh
npm install -g @atmem/architect@0.2.5
atmemai
```
