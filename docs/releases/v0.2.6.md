# AtMem AI Architect 0.2.6

- Create 28 diagram types from the shared architecture model, with accessible Mermaid insert/edit actions, page navigation, element libraries and linked Spec Kit properties.
- Drag, resize and rotate shapes. Pan by dragging blank canvas, holding Space, or using the middle mouse button. Wheel/pinch zoom preserves the pointer position.
- Read short shape titles and numbered connections; inspect full descriptions, fields and contracts separately.
- Preserve presentation edits independently of requirements and design records. SVG and editable pages share verified routes and label positions; unreadable exports report the affected elements.
- See upload/build state, interrupted-job recovery and consistent design readiness across project stages.
- Public examples use the synthetic AI knowledge assistant. Client documents, handoffs and audit evidence are excluded from the public distribution. Release checks inspect source and nested package archives using a private content policy.

```sh
npm install -g https://github.com/aetna000/atmem-ai-architect/releases/download/v0.2.6/atmem-architect-0.2.6.tgz
atmemai
```

The qualified release is public on GitHub. npm has accepted publication and public registry processing is pending; see [publication status](v0.2.6-publication.md).

Save open projects before restarting an existing instance. Project storage and local AtMem memory remain in the existing data directory.

Large diagrams need focus or panning; Fit is an overview. Routing is bounded and obstructed layouts can require smaller views or manual repair. The bundled example's runtime evidence uses local fixtures and mocked AWS. Architecture completeness, real mobile manipulation, physical Safari behavior and deployment require their own verification.
