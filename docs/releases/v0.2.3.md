# AtMem AI Architect 0.2.3

Stable release. Run `npx @atmem/architect@0.2.3` or update with `npm install -g @atmem/architect@0.2.3`.

- Slimmer project toolbar and stage navigation; the next action stays beside the stages on one line.
- A clearly labeled message field stays beside history on smaller screens.
- Delivery refreshes as generation and checks finish. Reopening a design preserves package binding across empty pricing defaults.
- Complete reference example remains available with its own source, costs, implementation and check evidence.
- Existing local model connections, AtMem memory, checks and project exports remain supported.

Hosted access uses the same application through authenticated project and isolated worker adapters. Website publication is separate from npm. Administrator activity reports, handle/nickname labels, explicit handle conversion and Google Analytics are hosted features; they do not add analytics to local installations.

Limits: browser GUI checks that cannot execute remain incomplete. Cloud voice and a second invited user's live isolation journey remain unqualified. X conversion requires X API access/credits when invoked. Publishing npm does not deploy Firebase Hosting, client infrastructure or the Orca plugin.
