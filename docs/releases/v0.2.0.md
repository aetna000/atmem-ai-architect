## Included

- Five-stage design workflow and one complete project ZIP.
- Concise controls, chat history visibility, and actionable final checks.
- Automatic partial cost estimates, Recalculate, editable placement, and persistent exact-file Terraform receipts.
- Searchable memory table, cursor pages, Default profile, creator/actor governance, and scoped external context providers.
- Open in Orca and its website link.
- Apache-2.0 for AtMem-owned code, with third-party notices retained.

## Verification and boundaries

Packaged startup, UI, and real AtMem are checked on Windows, macOS, and Linux. Independent local tests retain exact evidence.

The million-record benchmark qualifies dashboard reads only. Full native Windows generation/export and actual Orca desktop launch remain unqualified.

Missing service prices, usage, implementation, and checks remain explicit. Generation needs a supported signed-in agent and configured local tools.

No cloud deployment or full-project acceptance is established by installation, model completion, or local checks.
