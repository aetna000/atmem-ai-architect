Keep provider versions and configurable inputs explicit, use stable resource addresses, declare references and dependencies, and review state/import and destructive changes. Run validation before claiming a valid sketch. S3, typed text-statistics Lambda and asynchronous word-count pipelines and bounded Bedrock summaries and explicitly selected keyword RAG and existing-principal access are generated; other resources and integrations remain engineering work.


Evaluate the exported configuration, not its filename or the model's description. A schema-valid empty configuration or review gate alone does not implement a workload. Reconcile required services, resources, permissions and edges against the resource schedule and generated files. Preserve unresolved-work gates until implementation and acceptance evidence exist; never advise deleting blockers merely to make plan pass.

Distinguish configuration parsing, installed-provider schema validation, policy/requirements review, account-specific plan, apply, runtime acceptance, update and cleanup. Bind evidence to the exact exported artifact. An absent test is unverified, not passed. Report missing generator support as product work, and regenerate from the project after a fix instead of hand-editing an export.

Use Outputs → Emulate locally before download for supported stateful service/runtime checks. Require its artifact-bound report; distinguish scripted models and authorizer envelopes from AWS inference/authentication. Emulation does not apply Terraform or prove deployment.
